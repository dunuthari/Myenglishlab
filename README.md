# My English Lab

A simple web app to help beginners learn the 12 English tenses, one at a time.

## Status

- Home page lists all 12 tenses; only **Present Simple** is built so far.
- Present Simple covers 4 sections: **Base**, **Question**, **Negative**, **WH Question**, each with a formula explanation and 10+ example sentences (English + Sinhala).

## Structure

```
index.html              Home page - all 12 tenses
tenses/present-simple.html   Present Simple lesson page
css/style.css            Shared styles
```

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server.
